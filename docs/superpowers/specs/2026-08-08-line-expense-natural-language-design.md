# LINE 代墊自然語言快速登記設計

## 目標

員工在 LINE Bot 個人聊天室以一句口語描述代墊內容。系統自行解析、補合理預設值並檢查資料是否足以登記；資料足夠時只顯示一次確認圖卡，員工確認後才寫入 Google Sheet。

## 使用方式

支援自由語序、常見口語與輕微錯字，例如：

- `代墊昨天 TOYOTA 拍攝餐費 850，我先付的`
- `我今天幫公司買硬碟 3280 有統編`
- `代墊停車 120 沒收據`
- `阿全先付剪輯硬碟 4500，還沒領錢`

員工不需要記住固定欄位順序；訊息包含「代墊」或能明確判斷為代墊登記意圖時觸發。

## 解析欄位

系統嘗試取得以下資料：

- 支出日期
- 專案名稱
- 消費項目
- 支出金額
- 項目分類
- 支出人
- 付款時程
- 支出人是否已領款
- 是否開立含統編發票
- 收據狀態或收據照片
- 備註
- 登記人 LINE User ID 與顯示名稱

## 預設值規則

員工未明確填寫時，採用以下預設：

- 日期：訊息送出當日，使用 Asia/Taipei 時區。
- 支出人：訊息傳送者；若文字明確指定其他內部成員，以文字為準。
- 付款時程：已支出。
- 是否已領款：否。
- 是否開立含統編發票：未開。
- 收據：未提供。
- 專案：只有文字明確出現專案時才填入；無法判斷時追問，不自行猜測。
- 分類：依項目語意對應既有表單分類；信心不足時追問。

金額不得猜測或使用歷史平均值補入。

## 完整性與信心判斷

必要欄位為支出日期、消費項目、支出金額、支出人、項目分類及專案名稱。

解析結果分為三種：

1. **可完成登記**：必要欄位齊全，且沒有矛盾；直接回傳確認圖卡。
2. **可補問完成**：只有少數必要欄位缺漏或信心不足；Bot 一次列出所有缺漏欄位，員工用一句話補充後重新判斷。
3. **不可安全登記**：金額格式不明、多人付款無法區分、日期或內容互相矛盾；不寫入表格，清楚指出需要修正的內容。

系統不得只因文字中出現數字就視為金額。例如「TOYOTA 2026」不能把 2026 判定為支出金額。

## 確認圖卡

資料足夠時只顯示一張圖卡，集中列出所有欄位，並提供：

- `確認送出`：寫入 Google Sheet。
- `修改`：提示員工用一句話描述要修改的欄位，例如 `金額改成 950，發票改為有統編`。
- `取消`：清除本次暫存，不寫入資料。

未經員工按下 `確認送出`，不得新增支出資料。

## 收據處理

- 同一個登記流程中傳送圖片時，圖片視為該筆支出的收據。
- 若文字明確寫「沒收據」或「無收據」，允許確認，但備註自動記錄未附收據。
- 若未提及收據，不阻擋登記，確認圖卡標示「未提供」。
- 收據上傳失敗時不得回報登記完成，並保留暫存讓員工重試。

## 資料流程

1. LINE Webhook 接收員工文字或圖片。
2. 驗證傳送者是否為內部員工，且來源為 Bot 個人聊天室。
3. 自然語言解析器抽取欄位、套用預設值並計算欄位信心。
4. 完整性檢查決定顯示確認圖卡、一次性補問或錯誤說明。
5. 員工確認後，後端呼叫既有 Google Apps Script API。
6. Apps Script 上傳收據並新增 Google Sheet 列。
7. 寫入成功才回覆完成；失敗則保留內容並提示重試。

## 狀態與逾時

- 每位員工各自保有一筆未完成登記，互不影響。
- 暫存有效時間維持 30 分鐘。
- 員工重新輸入新的「代墊」內容時，以新內容取代尚未確認的舊內容，並明確提示已更新。
- 完成、取消或逾時後清除暫存。

## AI 與安全邊界

- AI 只負責理解文字與提供結構化欄位，不直接操作 Google Sheet。
- 後端必須再次驗證 AI 回傳的欄位、選項與金額，不能直接信任模型輸出。
- AI 回傳必須符合固定 JSON 結構；無效輸出視為解析失敗並改用補問。
- 不把 LINE Channel Secret、Access Token、API Key 或收據內容寫入記錄或回傳訊息。
- AI 服務暫時不可用時，保留原有逐欄圖卡流程作為備援，不中斷登記功能。

## 測試與驗收

至少覆蓋以下情境：

- 完整的一句話能直接產生正確確認圖卡。
- 不同語序、中文數字、千分位與「元」都能正確解析金額。
- 日期支援今天、昨天、明確年月日，並使用台北時區。
- 根據 User ID 正確辨識周暐、高爾賢與阿全。
- 缺少專案或分類時只補問缺漏內容，不重走全部流程。
- 同一句包含多個數字時不誤判金額。
- 修改指令只更新指定欄位。
- 未按確認不寫入；重複按確認不產生重複列。
- Apps Script 或 Drive 失敗時不回報成功，且能重試。
- AI 無法使用時能切換回原有逐步登記流程。

## 成功標準

- 一般完整輸入從傳訊息到送出，最多只需一次確認點擊。
- 資料不足時，最多一次列出所有需要補充的欄位。
- 不因 AI 猜測而寫入錯誤金額。
- Google Sheet 不產生未確認、重複或部分完成的資料。
